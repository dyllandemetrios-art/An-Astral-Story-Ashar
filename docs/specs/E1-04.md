# E1-04 — Dash
**Semaine** : S1 (1–7 oct) · **Estimation** : 1 ½ j · **Dépend de** : E1-02 · **Références** : `CLAUDE.md`, `docs/CAHIER_DES_CHARGES.md`

- **Fichiers** : `Features/Player/Scripts/PlayerDashController.cs`.
- **À faire** : dash de `dashDistance` en `dashDuration`, dans la direction de l'entrée (vers le haut sans entrée), invulnérable pendant `dashInvulnTime`, cooldown ; traînée visuelle provisoire.
- **Critères** : le dash ne traverse pas les limites ; il est impossible de dasher pendant le cooldown ; un booléen `IsInvulnerable` est lisible par `PlayerHealthController`.
- **Test** : enchaîner les dashes, puis vérifier le cooldown avec un compteur de débogage.
- **Conventions** : celles de `CLAUDE.md` (commentaires anglais pédagogiques, `[Tooltip]`, dossiers par fonctionnalité, prefabs, scène rangée). Elles font partie des critères d'acceptation.

## Compte rendu (rempli par Claude Code, en français)

**Branche** : `story/E1-04-dash`, créée à partir de `fix/controls-mapping-v2.4` (chaîne à fusionner dans l'ordre : P0-12, E1-01, E1-02, P0-15, E1-03, fix des commandes, E1-04).

- **Fichiers modifiés** :
  - Scripts : `Features/Player/Scripts/PlayerDashController.cs` (nouveau). `PlayerMovementController.cs` gagne une référence optionnelle au dash et se met en retrait pendant le dash, pour qu'un seul script déplace le vaisseau.
  - Données : `PlayerShipData` gagne `dashDistance` (2,8 u), `dashDuration` (0,18 s), `dashInvulnTime` (0,28 s) et `dashCooldown` (1,5 s). `PlayerShipData_Default.asset` a été réenregistré : la vitesse de déplacement (9) et les valeurs de tir sont inchangées.
  - Prefab : `PlayerShip` reçoit le `PlayerDashController` et un enfant `DashTrail` (`TrailRenderer`). Scène `TestBed` : le dash est relié à la `PlayArea`.
  - Tests : `Tests/EditMode/DashMathTests.cs` (10 cas : direction sans entrée, dérive du stick, diagonale, demi-stick, conditions de départ, distance exacte, arrêt sur le bord). Total : 43 tests, tous verts.
  - Commande : action `Dash` = **M** ou **V** au clavier, **RT** à la manette (mapping v2.4).
- **Règles retenues** (à valider) : la direction est fixée au départ du dash (entrée de déplacement, sinon vers le haut) ; le **cooldown et l'invulnérabilité se comptent tous les deux depuis le début du dash** (1,5 s entre deux départs, invulnérable 0,28 s soit 0,10 s de plus que le dash) ; un dash n'est pas interrompu si on lâche la direction ; un demi-stick donne un dash de pleine longueur.
- **Comment tester en 2 minutes** :
  1. Ouvre `TestBed`, lance le Play. Appuie sur **M** (ou **V**, ou RT à la manette) sans rien d'autre : le vaisseau file vers le haut de 2,8 unités, avec une traînée bleue.
  2. Maintiens une direction (par exemple Q ou D, ou une diagonale) et appuie sur M : le dash part dans cette direction.
  3. Enchaîne les appuis : un seul dash toutes les 1,5 s ; les appuis pendant le délai sont ignorés.
  4. Dash vers un bord : le vaisseau s'arrête sur le cadre vert, il ne sort jamais.
  5. Sélectionne `PlayerShip` : sous `Debug` du `PlayerDashController`, `Cooldown Left`, `Invulnerability Left` et `Is Dashing` servent de compteur de débogage. Change `Dash Distance` ou `Dash Cooldown` dans `PlayerShipData_Default` : effet immédiat.
  - Déjà vérifié de mon côté (Play Mode, image par image, dash automatique de débogage) : un dash de 2,8 u en 0,18 s (le vaisseau va de y = -3,5 à y = -0,7) ; invulnérabilité de 0,28 s ; départs espacés de 1,52 s (75 images de cooldown, plus l'image de reprise) ; au bord supérieur (y = 4,93) un dash ne bouge plus le vaisseau ; traînée derrière le vaisseau sur la capture ; console propre.
- **Limites connues** :
  - **Le vrai bouton n'a pas pu être testé par moi** (même limite qu'en E1-02 et E1-03). Le cooldown, la distance et l'invulnérabilité sont vérifiés avec le dash de débogage ; le branchement M / V / RT → dash est à confirmer par toi (étapes 1 à 3).
  - Case `Debug Always Dash` sur le `PlayerDashController` : dash dès que le délai le permet, sans appuyer. Décochée par défaut.
  - `IsInvulnerable` est prêt à être lu, mais `PlayerHealthController` n'existe pas encore (E1-05 et suivantes) : aucun impact visible avant.
  - Pendant le dash, le tir continue à fonctionner et le vaisseau ne réagit pas aux directions (le dash décide seul). C'est un choix simple à changer si tu préfères pouvoir corriger la trajectoire.
  - La traînée est provisoire : un rectangle bleu dégradé, avec un matériau créé à la main. À remplacer par un effet du pack (propulseurs) en S1 (E1-06) ou plus tard.
  - Le dash n'est pas encore désactivé pendant un dialogue (pilote automatique : stories E3).
- **Placeholders créés** : `Features/Player/Art/Placeholder/DashTrail.mat` (matériau de la traînée provisoire, `TrailRenderer` de l'enfant `DashTrail` du prefab `PlayerShip`).
- **Idées notées** : aucune nouvelle.
