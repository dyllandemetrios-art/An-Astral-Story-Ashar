# P0-07 — Contrat de prototype des deux boss

Statut : cadrage prototype prêt. Trame Dyllan prioritaire ; chiffres suivants sont des hypothèses réglables, jamais une validation finale d'équilibrage.
Réutiliser patterns existants. Aucun miniboss supplémentaire ni ancienne phase LEASH transmission.

## Boss Assemblée

Apparition blanche/rouge, entrée vers le haut de l'arène, pas de dégâts de contact pendant présentation.
Combat après présentation et éventuel dialogue fourni seulement. Prototype : alternance tir visé et éventail existants, intervalle 2 s exposé.
PV de départ = dégâts nominaux du tir niveau 1 par seconde × 30 s, calculés pour créer les nouvelles données puis réglables ; aucune adaptation dynamique aux dégâts du joueur.
Pulse stun suspend déplacement, tirs, temps de phase ; boss reste vulnérable. Destruction lance la suite Culte, aucun MissionEnd.

## Croiseur du Culte, entraves et alliés

Présentation inoffensive, trois captifs de prototype, chacun attaché par une entrave ciblable séparée. Nombre réglable, pas une quantité canonique imposée.
Radio captive_identification avant combat ; corps des captifs jamais hostile ni destructible par les tirs joueur. Pulse ne casse pas les entraves.
Prototype d'entrave : PV = DPS de base × 2 s ; destruction unique détache un captif. Le croiseur est invulnérable tant qu'une entrave subsiste, feedback clair d'objectif, pas de dégâts silencieusement perdus.
Pendant libération : pattern existant lent, intervalle 3 s réglable. Les alliés libérés rejoignent une formation et tirent immédiatement sur les ennemis hostiles disponibles ; s'il n'en existe aucun, ils restent en formation sans simuler une cible.
À trois captifs libérés : frontière narrative sécurisée E3-02, radio collective_assault, puis vulnérabilité du croiseur et assaut. Prototype sans vague additionnelle obligatoire.
Assaut : PV = DPS base × 45 s, patterns existants alternés intervalle 2 s, variables exposées. Chaque allié : 20 % du DPS de base, pas de tir ami ni de collision hostile. Ce sont des valeurs de départ à éprouver.
Le stun de boss doit bloquer aussi les transitions de phases ; aucune reprise de phase morte, double victoire ou reset de PV.
Victoire → épilogue, aucun écran. Captifs libérés persistent visuellement comme escorte selon E6-06.
Données pour nbCaptifs, PV, cadence, positions et dégâts ; aucun framework de boss générique requis.
